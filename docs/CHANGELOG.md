- **Milestone 122 The Mirza Cart brand** (2026-11-13, Architecture Decision Record 053; not deployed). The store is now "Mirza Cart": the default name changes (a migration renames a stored "Mirza" and nothing else), the surfaces move from warm ivory to clean neutrals (`#F8F8FA` page, `#F1F2F5` image wells, `#242328` text), and a shopping-cart logo replaces the "M" monogram in the header, footer, admin and favicon, with a new iPhone home-screen icon.
